🗣️ TTS Translator
A web application that translates text and reads it aloud using Text-to-Speech (TTS) technology. Built to practice API integration for language translation and voice synthesis.

📌 Overview
The TTS Translator app allows users to:

Translate text between multiple languages

Listen to the translated text using Text-to-Speech functionality

Simple and interactive interface for easy use

This project was developed for learning purposes, focusing on API integration and enhancing user experience with voice feedback.

🛠️ Tech Stack
HTML, CSS, JavaScript

Google Translate API (for translation)

Web Speech API (for Text-to-Speech)
